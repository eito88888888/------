# マジモン図鑑100枠のラインナップ案

> 状態: 提案。ゲームデータや図鑑仕様には未反映。

## 基本方針

- 図鑑は進化前・進化後をそれぞれ1枠として数え、合計100枠にする。
- 最初の3体は既存の3段階進化を維持し、分岐進化は作らない。
- 分岐進化は一部のレアな系統だけに設け、分岐先の姿も100枠の中に含める。
- 既存の能力値であるHP・攻撃・防御を軸に、見た目だけでなく戦い方も変える。
- 既存コードでは初期マジモン3体、野生11体、城ボス11体の計25種を扱っている。初期3体の進化段階はレベル10・30。

## 100枠の内訳

| 区分 | 算出 | 枠数 |
| --- | ---: | ---: |
| 初期マジモン | 3系統 × 3段階 | 9 |
| 既存の野生マジモン | 11系統 × 3段階 | 33 |
| 既存の城ボス | 11体 × 1段階 | 11 |
| 既存野生系統のレア分岐先 | 7系統 × 追加1段階 | 7 |
| 新規進化系統 | 13系統 × 3段階 | 39 |
| 進化しないレア枠 | 1体 | 1 |
| **合計** |  | **100** |

分岐先は初期3系統には設けない。既存野生11系統のうち7系統に1つずつ追加し、残り4系統は一本道とする。

## 初期マジモン

初期3体は個性が分かりやすい役割として固定し、進化先も一本道にする。

| 系統 | 進化ライン | 役割 |
| --- | --- | --- |
| ゴロー | ゴロー → ゴロウル → ゴロガード | 高HPから防御重視へ |
| ワニール | ワニール → ワニザウル → ワニキング | 高攻撃のアタッカー |
| カメタロウ | カメタロウ → カメガメ → カメダイオ | 高防御のタンク |

## 既存野生マジモンの進化

現在の野生マジモン11体をそれぞれ3段階の系統に広げる。以下の7系統に分岐先を1つずつ設ける案。候補の割り当てと方向性は仮で、分岐先は希少な進化条件や特別な進化アイテムで解放する。

| 現在の姿 | レア分岐の方向性 |
| --- | --- |
| ハネッコ | 日差しを浴びる「光翼」系 |
| モリモン | 森を守る「森番」系 |
| ぷかり | 沼に適応した「毒沼」系 |
| コロガル | 鉱石をまとった「鉱岩」系 |
| そよまる | 風を操る「嵐走り」系 |
| サンゴン | 深海に適応した「深海殻」系 |
| ルナモ | 月光をまとう「月影」系 |

残りの4系統（モコリン、キラボシ、ユキポン、くもたろう）は分岐なしの一本道とする。分岐条件はランダムにせず、プレイヤーが狙って達成できる方法にする。

## 進化しないレア枠

**ニジコトリ**（仮称）。出現率は低く、色が変わるだけでなく、味方を支援するなど独自の戦闘上の役割を持たせる。

## 実装時に確認すること

- 現在の図鑑は進化形を独立した枠として数えない。100枠にする際は、進化形・分岐先を図鑑データ上で別エントリーとして登録する。
- 初期3体は一本道を維持する。分岐進化はレア枠として扱い、分岐先7枠を含めて総数100に収める。
- 城ボス11体は現状の強敵枠として残し、追加ラインは植物・虫・毒・音・夢などのモチーフを広げる。
- 名称、進化条件、能力値、出現地域は今後の調整対象。
